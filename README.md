# Посмотри в окно 

Проектная работа по вёрстке для курса "Фронтенд-разработчик" в Яндекс Практикуме.

## Описание
Адаптивная верстка интерфейса приложения для просмотра видео из разных городов. В проекте реализованы стили для карточек видео, кастомных форм поиска, кнопок, а также позиционирование прелоадеров и обработка состояний элементов (наведение, фокус, активное состояние).

## Технологии
- HTML5
- CSS3 (Flexbox, Grid, кастомные свойства, псевдоклассы, псевдоэлементы)
- JavaScript (готовый скрипт логики приложения)
